# 上海外国语大学2026年推免招生信息

发布于2025年9月13日

## 关键时间节点

| 时间 | 事项 |
|------|------|
| 9月2-13日 | 在研招报名系统进行预报名 |
| 9月15日前 | 查询复试资格 |
| 9月18-21日 | 参加校内推免复试 |
| 9月22日9:00 | 在国家推免服务系统中报考专业、研究方向 |
| 9月23日9:00 | 院系在国家系统发送复试通知 |
| 9月25日9:00 | 发送待录取通知 |
| 9月25日14:00 | 考生须接受待录取 |

## 报考条件

- 中国公民，思想品德良好
- 纳入普通本科招生计划的四年制2026届应届本科毕业生
- 预计可获得本科学校普通推荐免试名额
- 入学前需取得本科毕业证和学士学位证

## 考核形式

- 专业笔试（满分100分）+ 专业面试（满分100分）
- 两项成绩均需60分及以上方予录取
- 笔试和面试各占50%权重
