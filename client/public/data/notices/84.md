# 湖北大学文学院2026届推免招生信息

## 申请资格要求

申请A类免试研究生需满足以下条件：
- 全日制在籍应届本科毕业生
- 具有高尚的爱国主义情操和集体主义精神
- 修完前三学年课程
- **关键要求**：同年级同专业前三学年加权平均成绩排名不低于50%

C类免试按照团中央文件执行。

## 关键时间安排

| 时间 | 事项 |
|------|------|
| 9月4-6日 | 学生自主申请 |
| 9月6日17:00前 | 材料提交截止 |
| 9月7-9日 | 审核评议阶段 |
| 9月9-12日 | 公示拟推荐和候补名单（公示4天） |
| 9月12日前 | 向本科生院上报材料 |

## 评分体系

综合成绩 = 学业成绩分 + 素质成绩分（最高20分）

素质成绩构成：
- 竞赛获奖：35%
- 科研成果：35%
- 参军入伍：10%
- 志愿服务：10%
- 实习实践：10%

## 重要提醒

- 所有材料一定按时交齐，过期不候、过期不补
- 获得推免资格者必须签署承诺书
- 承诺本科阶段不得办理出国、就业手续
