# 安徽师范大学2025年推免生招生信息

## 核心招生指标

- 推免硕士生：424人（含研究生支教团15人、硕师计划65人）
- 直博生：8人

## 关键时间节点

- **预报名截止**：9月24日前需发送预报名登记表至各学院指定邮箱
- **全国推免服务系统开通**：预计9月28日（由教育部确定）

## 申请条件要点

- 获得经教育部审批具有推免权高校的推荐免试资格
- 需在全国推免服务系统备案方才有效
- 直博生申请需提供两份专家推荐信

## 复试形式

各研究生培养单位自行确定复试日程和形式，申请人需及时查看邮箱并保持手机畅通。

## 招生专业

- 硕师计划涵盖12个教育硕士专业（思政、语文、数学等）
- 直博生限物理学、化学、生物学三个专业

**注**：具体英语要求请参阅各学院细则。
