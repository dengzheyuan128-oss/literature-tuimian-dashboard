- **dataLoader.ts的Schema检测机制**: 通过`schemaVersion`字段自动识别v1/v1.1，无需手动配置

- **链接质量分级**: A/B/C/D四级分类已实施，check-data-quality.js可自动检测

### 业务决策
- **停损线原则**: D级=0，健康度≥90%，第一梯队A级=100%，达标即停
